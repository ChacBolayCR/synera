# SYNERA

Demo administrativa y analítica para comercios construida con Next.js App Router, TypeScript, Tailwind CSS, Recharts y Lucide React.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Validación

```bash
npm run lint
npm run build
```

## Producción

```bash
npm run start
```

El proyecto utiliza el toolchain oficial de Next.js y puede importarse directamente en Vercel.
